# ESCC 病歷摘錄工作台（測試版）

線上試用：https://jnynlin.github.io/escc-abstraction-test/

**僅供測試，請勿輸入任何真實病人資料。** 資料只存在你自己的瀏覽器（加密），不會上傳到任何地方。

試用步驟
1. 開啟上方網址 → 建立資料管理帳號（復原碼測試時可不必保存）。
2. 右上「帳號管理」→ 新增一個登錄人員帳號。
3. 右上「分派病人」→「匯入加密分包」→ 選 `DEMO_synthetic_20_patients.escpkg.json`（先從本頁下載），分包密碼：`demo-package-2026`。
4. 勾選登錄人員 →「把尚未分派的病人平均分給勾選的人」。
5. 右上「鎖定」→ 用登錄人員帳號登入，開始試填。

分包內 20 位病人全部是隨機產生的假資料。
